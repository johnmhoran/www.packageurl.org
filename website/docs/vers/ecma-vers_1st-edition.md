# ECMA-xxx-VERS 1st Edition

The [ECMA-xxx-VERS 1st Edition](https://ecma-tc54.github.io/ECMA-xxx-VERS/)
standard has been approved by Ecma Technical Committee 54 (TC54). It is
pending approval by the Ecma General Assembly in December 2026 at which time
it will be assigned a standard number in the format "ECMA-xxx".

The content of **ECMA-xxx-VERS** is a subset of the overall VERS specification
but its content defines the normative standard. Some elements of the
specification that are not currently included in **ECMA-xxx-VERS 7** are the
How-to guides, the VERS Test Schema, the VERS test cases, and the data for
registered VERS `type` definitions.

A reference to the "VERS standard" is always a reference to **ECMA-xxx-VERS**.
A reference to the "VERS specification" may refer to information from
**ECMA-xxx-VERS** or from the broader VERS specification which is maintained
in the [vers-spec](https://github.com/package-url/vers-spec) repository on
GitHub.

The key elements of **ECMA-xxx-VERS 1st Edition** are:
- [Introduction](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-intro)
- [Clause 1 - Scope](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-scope): A
  brief statement of the ECMA-xxx-VERS scope.
- [Clause 2 - Conformance](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-conformance):
  This clause defines conformance to the VERS standard.
- [Clause 3 - Normative References](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-normative-references): This clause lists 3 external documents that are
  normative   references for the VERS standard.
- [Clause 4 - Overview](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-overview):
  This is a non-normative overview of the VERS standard.
- [Clause 5 - VERS Specification](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-vers-specification): This clause is the primary normative text for the VERS
  standard.
- [Clause 6 - VERS Type Definition Schema](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-vers-type-definition-schema): This clause is a human-friendly version of
  the JSON schema for VERS `type` definitions.
- [Annex A - VERS Type Definition Schema](https://ecma-tc54.github.io/ECMA-xxx-VERS/#sec-schemas): This annex provides a copy of the VERS Type Definition Schema:
  `vers-type-definition.schema-1.0.json` in JSON format.

The **ECMA-xxx-VERS** standard is maintained in the [ECMA-xxx-VERS](https://github.com/Ecma-TC54/ECMA-xxx-VERS) repository on GitHub.
