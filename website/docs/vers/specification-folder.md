# VERS Specification

The [ECMA-xxx-VERS 1st Edition](https://ecma-tc54.github.io/ECMA-xxx-VERS/)
standard has been approved by Ecma Technical Committee 54 (TC54). It is
pending approval by the Ecma General Assembly in December 2026 at which time
it will be assigned a standard number in the format "ECMA-xxx".

The key elements of the current VERS specification are:
- **ECMA-xxx-VERS 1st Edition**: This is the normative specification for VERS
  (Version Range Specifier).
- **Use cases**: Discussion of some common VERS use cases and examples.
- **How to parse and validate VERS**: Instructions for validating and parsing
  a VERS. This information is part of the VERS specification but not currently
  included in the **ECMA-xxx-VERS** standard.

The VERS specification is supported and extended by the <Link to="/docs/vers/test-suite">VERS test suite</Link>.
