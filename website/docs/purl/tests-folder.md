# Tests

The PURL (Package-URL) specification includes a comprehensive test suite to 
support implementation of PURL. The test suite is organized in 3 dimensions:
- **Test level**: specification-level tests or tests that are for a specific
  registered PURL type
- **Test group**: tests that are 'required' for conformance with the
  [ECMA-427](https://ecma-international.org/publications-and-standards/standards/ecma-427/) PURL Standard plus tests that are 'recommended' for 
  normalizing PURL data to canonical form
- **Test type**: tests for 'build', 'parse' or 'validate' use cases

See the following for more detailed information:
- **Test overview**: explains PURL test conformance and terminology
- **Test suite**: explains the structure of the test suite, test files, and
  test cases with details about test case properties
- **Test schema changes**: explains the differences between v0.2 and v0.1 of 
  the PURL test schema
